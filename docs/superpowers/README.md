# Closed archive — completed plans and specs

Everything under this directory is **history, not contract**. These are the
implementation plans and design specs that drove phases 0–7 and the post-v1
clone work. They were accurate when written and are kept verbatim because ADRs
and DEVLOG entries link to them by path.

Do not read these to learn how tgcli behaves today, and do not update them when
behaviour changes. The live documents are:

- [../CONTRACT.md](../CONTRACT.md) — the CLI automation contract
- [../MAP.md](../MAP.md) — what exists and where
- [../ISSUES.md](../ISSUES.md) — deferred work and its re-entry gates
- [../decisions/](../decisions/) — the decisions that still bind

The directory name is a leftover from the workflow that produced the plans; it
is kept only so the 67 existing links from ADRs and DEVLOG stay valid.
